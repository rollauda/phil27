Objectif / subjectif / intersubjectif​

Repère officiel du programme

Est objectif ce qui est conforme à l'objet, indépendant du sujet ; subjectif ce qui dépend du sujet particulier ; intersubjectif ce qui est partagé par plusieurs sujets et vaut entre eux.

  • Une mesure physique se veut objective ; un goût est subjectif ; un accord entre chercheurs, une langue, une norme sociale sont intersubjectifs.
  • L'intersubjectivité offre une voie moyenne : sans atteindre l'objectivité absolue, un accord entre sujets fonde une validité partagée (utile pour les sciences humaines).

Obligation / contrainte​

Repère officiel du programme

La contrainte est une force extérieure qui s'impose physiquement ; l'obligation est un devoir moral qui s'adresse à une volonté libre.

  • On est contraint par la menace ou la force (« je ne peux pas faire autrement ») ; on est obligé par le devoir (« je dois, mais je pourrais désobéir »).
  • L'obligation morale suppose donc la liberté : seul un être libre peut reconnaître un devoir. Bergson montre toutefois que l'obligation sociale prend souvent la forme d'une pression quasi automatique.

Termes liés : par devoir, morale, déterminisme.

Origine / fondement​

Repère officiel du programme

L'origine est le commencement dans le temps (d'où vient une chose) ; le fondement est ce qui la justifie en droit (ce qui la légitime).

  • Question d'origine : comment le langage, l'État, la morale sont-ils apparus ? Question de fondement : qu'est-ce qui les rend légitimes ?
  • Les deux sont indépendantes : connaître l'origine historique d'une valeur (sa généalogie) ne dit pas si elle est fondée en raison.

Termes liés : fondement.
