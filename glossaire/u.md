# U

## Universel / général / particulier / singulier {#universel-general-particulier-singulier}

:::info[Repère officiel du programme]
:::

Quatre degrés d'extension d'un jugement : l'**universel** vaut pour tous les cas sans exception ; le **général** pour la plupart ; le **particulier** pour quelques-uns ; le **singulier** pour un seul.

- « Tous les hommes sont mortels » est universel ; « les hommes sont généralement sociables » est général ; « certains hommes sont philosophes » est particulier ; « Socrate est mortel » est singulier.
- L'universel se distingue du général par sa nécessité : il ne « tolère aucune exception », tandis que le général admet des cas contraires.
